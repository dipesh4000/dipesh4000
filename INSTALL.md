# Apply to `dipesh4000/dipesh4000`

This bundle is designed to be additive. It does **not** generate, overwrite, or modify the existing Codolio DSA SVG/workflow.

## Files to add

```text
README.md
.github/workflows/profile-dashboard.yml
scripts/generate_profile_cards.py
assets/about.svg              # generated by the workflow
assets/contributions.svg      # generated by the workflow
assets/popular-repos.svg      # generated by the workflow
assets/achievements.svg       # generated by the workflow
```

Replace the current profile `README.md` with the bundled one, then add the workflow and script. Run the workflow once with **Actions → Refresh profile dashboard → Run workflow**.

The workflow refreshes daily and commits only these four generated SVG cards. Your existing `assets/dsa-stats.svg` remains untouched.

## One path discrepancy to check

The public repository currently exposes a folder named `assests/`, while the requested DSA path is `assets/dsa-stats.svg`. The new dashboard intentionally uses `assets/dsa-stats.svg` because that is the path specified for the existing working DSA card. If your live DSA SVG is actually under `assests/`, change only that single README reference; do not rename or move the DSA workflow just for this dashboard.
